# RIDEAU

Pupitre de conduite Phoenix LiveView. L'interface est en français, dessinée à la main dans `assets/css/app.css` (Fraunces, Barlow Condensed, Literata). Ne pas la remplacer par un thème Tailwind ou daisyUI.

Le parcours critique est le pupitre : Préparez, Top, réception sur un poste via PubSub. Les tests vivent dans `test/rideau/conduite_test.exs` et `test/rideau_web/pupitre_live_test.exs`.
